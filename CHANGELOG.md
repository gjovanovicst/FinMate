# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html) once it reaches 1.0.

FinMate is **pre-1.0 and has no tagged releases yet**. Until the first release, `main` is the only
supported version and the authoritative history is the commit log:

```bash
git log --oneline
```

Entries below are added when a version is tagged, not per commit.
